# 绿意 · 静心 —— 轻音乐 × 植物介绍

一个**单文件**网站：自动播放舒缓轻音乐 + 8 种植物介绍，UI 简洁干净。

- 轻音乐：Web Audio API 实时合成（无音频文件、无版权、可离线、零依赖）
- 植物：绿萝 / 龟背竹 / 多肉 / 仙人掌 / 白掌 / 芦荟 / 吊兰 / 富贵竹
- 移动端优先（NFC 刷卡场景基本都是手机打开）

## 本地预览

直接用浏览器打开 `index.html` 即可。

## 怎么「导入 NFC 卡片」

NFC 卡（NTAG213/215/216 等）容量只有几百字节，**存不下整个网站**，它存的是**一个网址**。
手机刷卡片 → 读取网址 → 自动打开浏览器访问本网站。所以步骤是：

1. **把网站部署到公网**，得到一个 https 网址（任选其一）：
   - **GitHub Pages**（免费）：新建仓库 → 上传 `index.html` → Settings → Pages → 得到一个 `https://你的用户名.github.io/仓库名/` 网址
   - **Netlify / Vercel**（免费）：直接拖拽项目文件夹上传，几秒得到网址
   - 也可以放在你自己的服务器 / 对象存储（如 OSS + 自定义域名）

2. **把网址写进 NFC 卡**：
   - 手机安装 **NFC Tools**（iOS / Android 均有免费版）
   - 打开 App → 「写入」→ 添加记录 → **URL / URI** → 粘贴上面得到的网址 → 写
   - 把手机贴近 NFC 卡，提示写入成功即可

3. **验证**：用手机后盖轻触 NFC 卡，会自动弹出浏览器打开网站。

> 提示：写 URL 时选「https://」开头的完整地址；卡片可重复擦写，改网址后重写即可。

## 关于「自动播放」

所有现代浏览器都会拦截「无用户操作的自动发声」。
本网站已做最优雅的处理：页面加载时自动尝试播放；若被拦截，会出现一个「开始聆听」按钮，点一下即进入自动循环播放，之后无需再操作。
